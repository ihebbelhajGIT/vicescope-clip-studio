# ViceScope Clip Studio

An experimental Windows desktop application for source-rights tracking and local video clipping. It does not upload or publish videos. Python 3.11+, FFmpeg and FFprobe are required; install dependencies with `.venv\Scripts\python.exe -m pip install -r requirements.txt` and launch with `.venv\Scripts\python.exe -m app.main`.

Choose a local source in Clip Editor, record permission evidence, explicitly approve and save it. The player allows playback, seeking and marking start/end positions. Highlight Finder ranks audio activity and optional transcript density as suggestions for review. Its transcript table allows timestamp and text editing; the current word is selected as the player runs. Whisper model download may be required. Choose center crop or blurred background, enter hook and title, and export to a new directory. A completed directory contains an MP4, metadata JSON and provenance JSON. Source and output hashes are checked before metadata preparation. Failed exports may leave an incomplete directory and are not shown as complete. Never treat a suggested highlight as proof of rights.

FFmpeg and FFprobe are detected from `.venv/ffmpeg-dist/*/bin` or PATH. Settings displays the detected paths. No media or models are included in this repository. An MIT software license does not grant rights to footage. Retain permission evidence and review all media and metadata before publication.

Run tests with `.venv\Scripts\python.exe -m pytest -q`. Synthetic integration tests cover rights, analysis, both layouts, rendering, hash checks, and package failure. Player playback and seek were checked using synthetic footage in an offscreen Qt session. No real source or speech transcription has been verified. Smart framing, facecam layout, adjustable caption style and credit positioning, rendered caption preview, accurate progress, cancellation, and real-footage end-to-end GUI testing remain incomplete. The current progress indicator is indeterminate. No automatic publishing is implemented.

See `docs/architecture.md` for the earlier audit and `THIRD_PARTY_NOTICES.md` for attribution. FFmpeg binaries and model weights are separate components with their own licenses.

## Automatic local production and review (experimental)

Register and explicitly approve an exact local source in Clip Editor, then select **Generate Shorts automatically** and an output folder. The app transcribes the source with faster-whisper, ranks audio and speech activity, selects non-overlapping candidates, renders each package, and adds it to **Ready for Review**. If transcription yields no reliable speech or candidates do not reach the minimum score, the app asks for manual review. The first transcription may need to download a model. This pipeline has been tested with synthetic video and an injected transcript; Whisper itself and real media have not been verified.

The review queue persists locally. Play clips, edit metadata, approve a particular media hash and metadata version for a future private upload, or reject it. Metadata edits invalidate approval; a rejected version cannot be approved. Saving metadata updates the local review record, not the original `metadata.json` in the export directory. Approval is a local review record: **no YouTube upload or publication is implemented**. Upload code, when added, must revalidate the current source, output hash and exact approved metadata immediately before transfer. Do not treat campaign text or discovery results as permission.

URL downloading, creator monitoring, OAuth, uploading, publication approval, regenerate-in-place, thumbnails, full crash recovery, cancellation, scene and reaction analysis, and persistent pipeline states are not implemented. The existing scorer uses audio RMS and transcript density; it is not a guarantee of an engaging highlight. Manually inspect clips and metadata. The GUI does not currently offer a configurable score or clip count.
