# ViceScope Clip Studio

ViceScope Clip Studio is a personal desktop application for finding and editing Shorts on Windows x64 and Apple Silicon macOS. It uses one Python/PySide6 codebase, native credential storage, and local media processing. Install from the [Windows guide](docs/windows-install.md) or [macOS guide](docs/macos-install.md), or [build a native package](docs/build-and-package.md).

In Clip Editor, choose an authorized local video and save its creator, evidence and explicit approval. Alternatively select **Import an authorized YouTube video**, enter the exact URL, creator and permission evidence, and explicitly approve that video before the download starts. Approval is specific to its YouTube ID, not every video from the creator. yt-dlp uses public access without browser cookies; restricted or inaccessible videos fail. Previously imported files are reused only if their exact permission and source hash still match. The YouTube acquisition boundary is covered by mocked tests but has not been tested with an authorized real video.

Select **Generate Shorts automatically** and an output folder. Choose a maximum clip count, target duration and minimum highlight score. The app transcribes the source, ranks moments using audio intensity, speech density, reaction phrases and visual scene changes, then renders non-overlapping suggestions. Stage progress is shown; cancellation waits for the current transcription, analysis or render step to finish. These are heuristics, not verified exciting moments. If no speech or candidate qualifies, review the source manually. Each generated directory contains a video, metadata and provenance hashes. Existing directories are never overwritten.

In **Ready for Review**, play clips, edit metadata, reject them, or record approval of the exact MP4 and metadata for a private upload. Metadata edits are synchronized to the package JSON and invalidate approval. Regeneration supersedes the old version only after a new unapproved clip and review record have been created and validated. Source, output and metadata are checked for changes before approval. Incomplete export folders are not reported as completed.

In **Ready for Review**, connect the intended ViceScope channel, approve the clip, and choose **Upload Privately**. After the upload, verify the channel, video details and privacy. Choose **Publish Publicly** and confirm to make the video public. See the [Google Cloud and YouTube setup guide](docs/youtube-setup.md) for credentials, project audit requirements, and interrupted uploads. The app cannot independently verify permission evidence. Review your rights before processing and publishing.

Run tests with `python -m pytest -q` from the platform’s virtual environment. The integration tests use generated media, mocked YouTube calls and an offscreen Qt session for review actions. A separate manual test used public speech, synthetic video and the actual `tiny.en` Whisper model through automatic rendering. Real creator footage, YouTube download, channel connection and uploads have not been verified. Caption quality and title suggestions still require review. Progress reflects completed pipeline stages, not an FFmpeg percentage; cancellation does not interrupt an active step. See `docs/architecture.md` for the earlier audit and `THIRD_PARTY_NOTICES.md` for attribution.

For the experimental in-app local-folder and exact-video monitoring workflow, see [Automation](docs/automation.md). Automatic channel and playlist discovery is not implemented.
