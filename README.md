# ViceScope Clip Studio

An experimental personal Windows application for finding and editing Shorts. Python 3.11+, FFmpeg and FFprobe are required. Install dependencies with `.venv\Scripts\python.exe -m pip install -r requirements.txt` and start the app with `.venv\Scripts\python.exe -m app.main`. Settings shows the detected FFmpeg paths. The first transcription may download a faster-whisper model. No paid service, server or automatic publishing is required.

In Clip Editor, choose an authorized local video and save its creator, evidence and explicit approval. Alternatively select **Import an authorized YouTube video**, enter the exact URL, creator and permission evidence, and explicitly approve that video before the download starts. Approval is specific to its YouTube ID, not every video from the creator. yt-dlp uses public access without browser cookies; restricted or inaccessible videos fail. Previously imported files are reused only if their exact permission and source hash still match. The YouTube acquisition boundary is covered by mocked tests but has not been tested with an authorized real video.

Select **Generate Shorts automatically** and an output folder. Choose a maximum clip count, target duration and minimum highlight score. The app transcribes the source, ranks moments using audio intensity, speech density, reaction phrases and visual scene changes, then renders non-overlapping suggestions. Stage progress is shown; cancellation waits for the current transcription, analysis or render step to finish. These are heuristics, not verified exciting moments. If no speech or candidate qualifies, review the source manually. Each generated directory contains a video, metadata and provenance hashes. Existing directories are never overwritten.

In **Ready for Review**, play clips, edit metadata, reject them, or record approval of the exact MP4 and metadata for a future private upload. Metadata edits are synchronized to the package JSON and invalidate approval. Regeneration supersedes the old version only after a new unapproved clip and review record have been created and validated. Source, output and metadata are checked for changes before approval. Incomplete export folders are not reported as completed.

**No YouTube connection, upload, or publication exists yet.** A local approval does not upload anything. Creator monitoring, analytics, duplicate upload prevention and public-publication approval are also pending. The app cannot independently verify permission evidence; review your rights before processing and publishing. The software license does not grant footage rights.

Run tests with `.venv\Scripts\python.exe -m pytest -q`. The included integration tests use generated media and mocked downloads. A separate manual test used public speech, synthetic video and the actual `tiny.en` Whisper model through automatic rendering. Real creator footage, YouTube download, channel connection and uploads have not been verified. Caption quality and title suggestions still require review. Progress reflects completed pipeline stages, not an FFmpeg percentage; cancellation does not interrupt an active step. See `docs/architecture.md` for the earlier audit and `THIRD_PARTY_NOTICES.md` for attribution.
